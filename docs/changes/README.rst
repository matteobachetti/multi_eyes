Changelog snippets
==================

Each pull request adds a short file here, named ``<PR number>.<type>.rst``, describing the
change in one or two sentences for users. Get the next PR number with ``nextpr``.
Types: ``breaking``, ``feature``, ``bugfix``, ``doc``, ``trivial``.

``towncrier build --version X.Y`` folds the snippets into ``CHANGES.rst`` at release time.
